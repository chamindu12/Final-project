Check your connection

Network access rules determine which portals you can reach. A valid password does not override those rules. If access is denied, use the correct network or ask your administrator for assistance.

Sign in again when needed

Sessions expire and are revoked when you sign out. If an action asks you to sign in again, reopen the sign-in page. If you receive a request error, reload the form before submitting it.

Understand test downloads

A test download sends a fixed-size file through the gateway. It generates traffic for monitoring; it does not measure your internet connection speed.
